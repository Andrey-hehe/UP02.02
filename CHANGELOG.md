# Changelog


### Added (Добавлено)
- Базовая функциональность чтения файлов (TXT и JSON).
- Алгоритм поиска различий для текстовых файлов (`difflib`).
- Функция умного сравнения JSON-файлов по отдельным полям.
- Генерация HTML-отчёта с подсветкой изменений.
- Интерфейс командной строки (CLI) с помощью `argparse`.
- 10 unit-тестов, покрывающих ключевую логику.
- CI-конвейер на GitHub Actions (Ruff + unittest).
- Шаблоны для Pull Request и Issues.

### Known limitations (Известные ограничения)
- Поддерживается только кодировка UTF-8.
- Нет графического интерфейса (только CLI).
- Нет нативного парсинга XML или YAML (только TXT и JSON).
