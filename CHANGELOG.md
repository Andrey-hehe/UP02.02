# История изменений

## [0.1.0] — к выпуску

### Добавлено

- Сравнение двух версий текстовых и JSON-файлов.
- HTML-отчёт с подсветкой добавлений, удалений и замен.
- API для сравнения полей JSON-объектов, включая вложенные объекты.
- Два unit-теста на сравнение текста и JSON. GitHub Actions проверяет код и публикует HTML-отчёт о покрытии.

### Исправлено

- CLI возвращает ненулевой код и выводит сообщение в stderr при ошибках чтения, записи и разбора JSON.
- Примеры запуска в README используют файлы из каталога `examples/`.

### Известные ограничения

- Входные файлы читаются в UTF-8.
- API сравнения JSON по полям принимает объекты в корне и показывает изменения массива целиком.
