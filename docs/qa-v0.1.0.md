# Ручное тестирование версии 0.1.0

Дата проверки — 25 ноября 2026 г. Среда — Windows, Python 3.12.
Утилита запускалась из корня проекта командой
`py -3.12 src/main.py <первый файл> <второй файл> -o <отчёт>`.
Для каждого сценария использовался новый путь к отчёту.

| № | Сценарий | Ожидаемый результат | Фактический результат | Статус |
|---|---|---|---|---|
| 1 | Сравнить `examples/first.txt` и `examples/second.txt` | Код 0, отчёт подсвечивает добавления, удаления и изменения | Код 0, HTML содержит разметку всех трёх типов изменений | Пройден |
| 2 | Сравнить JSON `{"user":{"age":20}}` и `{"user":{"age":21}}` | Код 0, в отчёте подсвечена замена значения `user.age` | Код 0, в отчёте подсвечены изменившиеся цифры 0 и 1 | Пройден |
| 3 | Сравнить `examples/first.txt` с самим собой | Код 0, отчёт без подсвеченных различий | Код 0, отчёт создан, ячейки сравнения не содержат разметки изменений | Пройден |
| 4 | Указать отсутствующий `missing.txt` первым входным файлом | Код 1, сообщение об отсутствующем файле, отчёт не создаётся | Код 1, сообщение в stderr, отчёт отсутствует | Пройден |
| 5 | Указать файл `invalid.json` с содержимым `{` и корректный JSON | Код 1, сообщение об ошибке разбора JSON, отчёт не создаётся | Код 1, сообщение разбора в stderr, отчёт отсутствует | Пройден |

По итогам этих пяти сценариев дефектов не выявлено.
